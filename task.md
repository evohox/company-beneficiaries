# Тестовое задание: конечные бенефициары компании

## 1. Предметная область

### Граф владения

Компании принадлежат кому-то: другим компаниям или физическим лицам.
Это отношение образует **ориентированный граф**:

* **вершины** — сущности двух типов: `person` (физическое лицо) и
  `company` (юридическое лицо);
* **рёбра** — факты владения. Ребро из `X` в `Y` со значением `s` означает,
  что `X` владеет долей `s` компании `Y`.

Физическим лицом владеть нельзя: рёбра всегда ведут в компанию.

### Прямая доля

**Прямая доля** `direct(X, Y)` — доля компании `Y`, записанная
непосредственно на `X`. Это то, что лежит в исходных данных.

### Цепочка владения

**Цепочка владения** — последовательность рёбер, ведущая от владельца к
компании через промежуточные юрлица:

```
Иванов ──0.5──▶ ООО «Альфа» ──0.4──▶ АО «Бета»
```

Иванов не записан во владельцах «Беты» напрямую, но контролирует её через
«Альфу». Вклад цепочки в его долю — **произведение долей вдоль неё**:
`0.5 × 0.4 = 0.20`.

### Эффективная доля

**Эффективная доля** `eff(X, Y)` — суммарная доля компании `Y`, приходящаяся
на `X` с учётом всех цепочек владения, прямых и косвенных.

Формальное определение — рекурсивное:

```
eff(X, Y) = direct(X, Y) + Σ  direct(M, Y) × eff(X, M)
                            M — компания
```

Читается так: доля `X` в `Y` складывается из того, чем `X` владеет в `Y`
напрямую, плюс доли всех компаний-владельцев `Y`, взвешенные тем, какая часть
каждой из них принадлежит `X`.

### Конечный бенефициар

**Конечный бенефициар** компании — физическое лицо с ненулевой эффективной
долей в ней. Именно их и нужно найти.



## 2. Примеры

### Пример 1. Цепочка — доли перемножаются

```
P1 ──0.5──▶ A ──0.4──▶ B
```
`eff(P1, B) = 0.5 × 0.4 = 0.20`

### Пример 2. Прямое и косвенное владение — складываются

```
P1 ──0.10────────────▶ C
P1 ──1.0──▶ A ──0.30──▶ C
```
`eff(P1, C) = 0.10 + 1.0 × 0.30 = 0.40`

### Пример 3. Ромб — доли по разным путям складываются

```
        ┌──1.0──▶ A ──0.40──┐
P1 ─────┤                   ├──▶ C
        └──1.0──▶ B ──0.35──┘
```
`eff(P1, C) = 1.0 × 0.40 + 1.0 × 0.35 = 0.75`

### Взаимное владение

В данных встречается **взаимное владение**: `A` владеет долей `B`, а `B` —
долей `A`. Определение эффективной доли остаётся применимым и в этом случае —
оно рекурсивное и допускает такие конфигурации. Как его при этом вычислить —
часть задачи.



## 3. Входные данные

### `entities.csv`

| колонка | тип | описание |
|---|---|---|
| `id` | строка | уникальный идентификатор сущности |
| `type` | `person` \| `company` | тип сущности |
| `name` | строка | ФИО или наименование юрлица |

```csv
id,type,name
P000000,person,Смирнов Иван Сергеевич
C000001,company,"ООО ""Стройинвест Групп"""
```

### `edges.csv`

| колонка | тип | описание |
|---|---|---|
| `owner_id` | строка | кто владеет |
| `owned_id` | строка | кем владеет |
| `share` | число | доля владения |

```csv
owner_id,owned_id,share
P013748,C007664,0.5242
C028071,C021204,0.5287
```

## 4. Что нужно сделать

### CLI-скрипт

```
python solve.py --entities entities.csv --edges edges.csv \
                --target C025145 --threshold 0.0001
```

| аргумент | описание |
|---|---|
| `--entities` | путь к файлу сущностей |
| `--edges` | путь к файлу рёбер |
| `--target` | идентификатор компании, для которой ищем бенефициаров |
| `--threshold` | порог отсечки: результаты со строго меньшей долей не выводятся |

### Формат вывода

CSV в stdout, с заголовком, отсортированный по убыванию доли:

```csv
person_id,name,effective_share
P000728,Морозов Николай Петрович,0.429208
P004236,Смирнов Михаил Петрович,0.271131
```

Только физические лица.
